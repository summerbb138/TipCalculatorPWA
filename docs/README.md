# Tip Calculator PWA

PWA version of the Tip Calculator. Same features as the native app, no 7-day expiry.

## How to Run
1. Serve this folder: `python3 -m http.server 8071`
2. On iPhone Safari: `http://<mac-ip>:8071`
3. Share → Add to Home Screen

## Data
All data stored locally in IndexedDB on-device.
